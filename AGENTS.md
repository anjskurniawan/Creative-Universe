# CreativeUniverse Project Rules

When working in this repository, use the project-local skills when the task matches their scope. Read the relevant `SKILL.md` completely before taking task actions.

- Component creation, catalog, preview, metadata, or component-folder work: read `skills/component-management/SKILL.md`.
- Single-target Developer Library synchronization: read `skills/update-library/SKILL.md`.
- Frontend styling, UI layout, responsive behavior, or visual design work: read `skills/frontend-styling/SKILL.md`.
- Route, page structure, navigation, or route refactoring work: read `skills/route-modularization/SKILL.md`.
- Any implementation, analysis, review, diagnosis, or validation work: read the relevant recent entries in `notes/logs/agent-work-log.md`, then follow `skills/log/SKILL.md` and record the result after the task.

These skills are project-local and apply only to this `creativeuniverse` workspace.
