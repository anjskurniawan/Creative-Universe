# React Aria Skill

> Status: Current
> Last verified: 2026-08-13

Use skills/react-aria/SKILL.md when a request mentions React Aria, react-aria-components, an Aria accessibility component, or a new reusable Universe component.

- The react-aria-components dependency is available in apps/frontend/package.json.
- Read the exact catalog or reference before selecting a primitive.
- For a new Universe component, perform the discovery gate and scaffold from a matching API.
- If no suitable primitive exists, record the no-match decision and implement appropriate accessibility.
- Do not use this skill in place of Spectrum S2 for an explicit Spectrum request.

See [component system](../frontend/component-system.md).
