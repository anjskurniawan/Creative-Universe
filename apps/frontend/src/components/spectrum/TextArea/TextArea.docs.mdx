# TextArea

This compatibility adapter provides a multiline field API using the official installed S2 TextField primitive. The S2 package version in this workspace does not currently export a `TextArea` subpath.

<Canvas of={Stories.Basic} />

Use `label`, `placeholder`, `value`, `defaultValue`, `onChange`, validation props, and `rows` for the local multiline sizing contract.
