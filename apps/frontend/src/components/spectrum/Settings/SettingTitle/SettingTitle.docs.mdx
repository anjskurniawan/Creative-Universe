# SettingTitle

`SettingTitle` is a reusable Settings page heading that applies the Spectrum S2 `heading-xl` typography style.

## Basic usage

```tsx
import {SettingTitle} from "@/components/spectrum/Settings/SettingTitle";

<SettingTitle title="Authentication" />
```

<Canvas of={SettingTitleStories.Default} />

## Content

The component accepts a title prop and an optional subtitle rendered with Spectrum body typography.
