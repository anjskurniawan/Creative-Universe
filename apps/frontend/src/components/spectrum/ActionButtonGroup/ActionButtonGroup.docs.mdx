<Description>
An ActionButtonGroup is a grouping of related ActionButtons. This wrapper uses React Spectrum S2 and automatically applies Spectrum styling, typography, color schemes, and accessibility behavior.
</Description>

## QA color scheme

Use the **Spectrum Light** or **Spectrum Dark** toolbar control in Storybook to inspect the group in both color schemes.

## Basic usage

Place related ActionButtons inside the group. Use `Text` alongside an icon to provide visible labels.

<Source language="tsx" code={`import { ActionButtonGroup, ActionButton, Text } from "@/components/spectrum/ActionButtonGroup";
import Cut from "@react-spectrum/s2/icons/Cut";
import Copy from "@react-spectrum/s2/icons/Copy";
import Paste from "@react-spectrum/s2/icons/Paste";

<ActionButtonGroup>
  <ActionButton aria-label="Cut"><Cut /><Text>Cut</Text></ActionButton>
  <ActionButton aria-label="Copy"><Copy /><Text>Copy</Text></ActionButton>
  <ActionButton aria-label="Paste"><Paste /><Text>Paste</Text></ActionButton>
</ActionButtonGroup>`} />
<Primary />

## Orientation and density

Set `orientation="vertical"` to stack buttons. Use `density="compact"` for tighter spacing, or keep the default `regular` density for standard spacing.

<Source language="tsx" code={`<ActionButtonGroup orientation="vertical" density="compact">
  <ActionButton aria-label="Cut">Cut</ActionButton>
  <ActionButton aria-label="Copy">Copy</ActionButton>
</ActionButtonGroup>`} />

## Justified and quiet groups

Set `isJustified` to divide the available width equally between buttons. Set `isQuiet` when the group should use the quiet ActionButton style. Use `staticColor="black"` or `staticColor="white"` when the group appears over a colored background.

## Disabled state

Set `isDisabled` on the group to disable all ActionButtons in the group consistently.
