# Badge

Badges show a small amount of color-categorized metadata and are ideal for getting a user's attention.

## Basic usage

```tsx
import {Badge} from "@/components/spectrum/Badge";

<Badge variant="informative">In progress</Badge>
```

<Canvas of={BadgeStories.Default} />

## Semantic variants

Use semantic variants such as `positive`, `negative`, `notice`, or `informative` when the badge communicates meaning. Use color variants such as `blue`, `purple`, or `green` for non-semantic categorization.

<Canvas of={BadgeStories.SemanticPositive} />
<Canvas of={BadgeStories.SemanticNegative} />

## Fill styles and overflow

Use `bold`, `outline`, or `subtle` with `fillStyle` to control the visual treatment. Set `overflowMode` to `truncate` when the badge must stay on one line, or use `wrap` for longer content.

<Canvas of={BadgeStories.Subtle} />

## Accessibility

Badge content should be concise and understandable without relying only on color. Use semantic variants when applicable and provide `aria-label` when the visible content does not fully describe the badge.

## API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `aria-describedby` | `string` | — | Identifies the element that describes the badge. |
| `aria-details` | `string` | — | Identifies detailed information about the badge. |
| `aria-label` | `string` | — | Defines an accessible name for the badge. |
| `aria-labelledby` | `string` | — | References the element that labels the badge. |
| `children` | `ReactNode` | — | The content to display in the badge. |
| `fillStyle` | `"bold" \| "outline" \| "subtle"` | `bold` | The fill treatment of the badge. |
| `id` | `string` | — | The element's unique identifier. |
| `overflowMode` | `"truncate" \| "wrap"` | `wrap` | Sets text behavior for badge contents. |
| `size` | `"S" \| "M" \| "L" \| "XL"` | `S` | The size of the badge. |
| `slot` | `string \| null` | — | A slot name for receiving parent props. |
| `styles` | `StylesProp` | — | Spectrum-defined styles returned by the style macro. |
| `UNSAFE_className` | `UnsafeClassName` | — | Custom class name, intended only as a last resort. |
| `UNSAFE_style` | `CSSProperties` | — | Inline style, intended only as a last resort. |
| `variant` | `accent \| blue \| brown \| celery \| chartreuse \| cinnamon \| cyan \| fuchsia \| gray \| green \| indigo \| informative \| magenta \| negative \| neutral \| notice \| orange \| pink \| positive \| purple \| red \| seafoam \| silver \| turquoise \| yellow` | `neutral` | Changes the background color or semantic meaning of the badge. |
