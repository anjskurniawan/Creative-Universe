`aria-label` wajib diberikan apabila Calendar tidak memiliki label visual yang terhubung. Gunakan `defaultValue` untuk nilai awal yang tidak dikontrol.

## Nilai controlled

Gunakan `value` dan `onChange` ketika tanggal perlu disimpan pada state atau disinkronkan dengan form.

<Source
  language="tsx"
  code={`import { parseDate } from "@internationalized/date";
import { useState } from "react";
import { Calendar } from "@/components/spectrum/Calendar";

function Example() {
  const [date, setDate] = useState(parseDate("2025-02-03"));

  return <Calendar aria-label="Tanggal pilihan" value={date} onChange={setDate} />;
}`}
/>

## Validasi dan ketersediaan tanggal

Batasi rentang dengan `minValue` dan `maxValue`. Gunakan `isDateUnavailable` untuk aturan tambahan seperti tanggal penuh atau akhir pekan. `isInvalid` dan `errorMessage` digunakan jika aturan validasi berasal dari aplikasi.

<Source
  language="tsx"
  code={`import { getLocalTimeZone, isWeekend, today } from "@internationalized/date";

const now = today(getLocalTimeZone());

<Calendar
  aria-label="Tanggal janji temu"
  minValue={now}
  maxValue={now.add({ months: 3 })}
  isDateUnavailable={(date) => isWeekend(date, "id-ID")}
/>`}
/>

## Tampilan dan fokus

- `visibleMonths` menampilkan beberapa bulan sekaligus.
- `firstDayOfWeek` mengatur awal minggu.
- `focusedValue` dan `onFocusChange` mengontrol bulan yang sedang terlihat.
- `pageBehavior="visible"` berpindah sebesar jumlah bulan terlihat; gunakan `"single"` untuk berpindah satu bulan.
- `isDisabled` menonaktifkan Calendar; `isReadOnly` mempertahankan nilai tetapi tidak mengizinkan perubahan.

## Internasionalisasi

Calendar memakai locale pengguna secara default. Berikan nilai dari `@internationalized/date` untuk parsing, manipulasi tanggal, zona waktu, atau sistem kalender lain. Untuk mengubah sistem kalender tampilan, gunakan `Provider` Spectrum dengan locale yang memakai Unicode calendar extension.

<Source
  language="tsx"
  code={`import { parseDate } from "@internationalized/date";
import { Provider } from "@react-spectrum/s2/Provider";
import { Calendar } from "@/components/spectrum/Calendar";

<Provider locale="id-ID-u-ca-gregory">
  <Calendar aria-label="Tanggal pilihan" defaultValue={parseDate("2025-02-03")} />
</Provider>`}
/>
