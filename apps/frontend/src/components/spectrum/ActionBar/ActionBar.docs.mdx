<Description>
Action bars are used for single and bulk selection patterns when a user needs to perform actions on one or more items at the same time. This wrapper automatically applies React Spectrum S2 styles, typography, color schemes, and accessibility behavior.
</Description>

## QA color scheme

Use the **Spectrum Light** or **Spectrum Dark** toolbar control in Storybook to inspect both color schemes.

## Basic usage

Pass `selectedItemCount` and place one or more `ActionButton` components inside the bar. The bar is hidden when the count is `0`.

<Source language="tsx" code={`import { ActionBar, ActionButton } from "@/components/spectrum/ActionBar";

<ActionBar selectedItemCount={2}>
  <ActionButton aria-label="Edit">Edit</ActionButton>
  <ActionButton aria-label="Copy">Copy</ActionButton>
  <ActionButton aria-label="Delete">Delete</ActionButton>
</ActionBar>`} />
<Primary />

## TableView, ListView, and TreeView

ActionBar is intended to be rendered by collection components through `renderActionBar`. Pass the selected collection size to `selectedItemCount` and keep the actions inside the bar. The same pattern works with `ListView` and `TreeView`.

<Source language="tsx" code={`<TableView
  aria-label="Table with action bar"
  selectionMode="multiple"
  renderActionBar={(selectedKeys) => (
    <ActionBar selectedItemCount={selectedKeys.size}>
      <ActionButton aria-label="Edit">Edit</ActionButton>
      <ActionButton aria-label="Copy">Copy</ActionButton>
      <ActionButton aria-label="Delete">Delete</ActionButton>
    </ActionBar>
  )}
>`} />

## Clearing selection

Use `onClearSelection` to connect the built-in clear-selection button to the state owned by the collection.

<Source language="tsx" code={`<ActionBar
  selectedItemCount={selectedKeys.size}
  onClearSelection={() => setSelectedKeys(new Set())}
>
  <ActionButton aria-label="Archive">Archive</ActionButton>
</ActionBar>`} />

## All items and emphasis

Use `selectedItemCount="all"` when every item is selected. Set `isEmphasized` to `true` when the actions need stronger visual emphasis.

<Source language="tsx" code={`<ActionBar selectedItemCount="all" isEmphasized>
  <ActionButton aria-label="Archive">Archive</ActionButton>
</ActionBar>`} />

`ActionButton` is re-exported from this wrapper for convenience. Its props include `aria-label`, `isDisabled`, `isQuiet`, `isPending`, `onPress`, and other React Spectrum S2 action behavior.
