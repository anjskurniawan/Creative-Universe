# InlineAlert

`InlineAlert` displays non-modal feedback associated with content in a view, such as form validation or operation status.

## Basic usage

Use `Heading` and `Content` from this wrapper to provide an accessible alert structure.

<Canvas of={Stories.Default} />

## Variants

Use semantic variants such as `negative`, `positive`, `notice`, `informative`, and `neutral` with `border`, `subtleFill`, or `boldFill` fill styles.
