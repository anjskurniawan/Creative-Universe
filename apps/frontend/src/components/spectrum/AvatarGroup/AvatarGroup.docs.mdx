# AvatarGroup

An avatar group is a grouping of avatars that are related to each other, such as project members or participants.

## Basic usage

```tsx
import {AvatarGroup, Avatar} from "@/components/spectrum/AvatarGroup";

<AvatarGroup label="Project members">
  <Avatar alt="Abraham Baker" src="/images/abraham-baker.png" />
  <Avatar alt="Adriana Sullivan" src="/images/adriana-sullivan.png" />
</AvatarGroup>
```

<Canvas of={AvatarGroupStories.Default} />

## Sizes

Use `size` to set the size of every avatar in the group. Supported values are `16`, `20`, `24`, `28`, `32`, `36`, and `40`.

## Accessibility

Provide a meaningful `label` or accessible labeling prop to describe the group. Each child Avatar should have meaningful `alt` text when it communicates identity.

## API

| Name | Type | Default | Description |
| --- | --- | --- | --- |
| `aria-describedby` | `string` | — | Identifies the element that describes the group. |
| `aria-details` | `string` | — | Identifies the element that provides detailed information. |
| `aria-label` | `string` | — | Defines an accessible name for the group. |
| `aria-labelledby` | `string` | — | References the element that labels the group. |
| `children` | `ReactNode` | — | Avatar children of the avatar group. |
| `id` | `string` | — | The element's unique identifier. |
| `label` | `string` | — | The label for the avatar group. |
| `size` | `16 \| 20 \| 24 \| 28 \| 32 \| 36 \| 40` | `24` | The size of the avatar group. |
| `slot` | `string \| null` | — | A slot name for receiving parent props. |
| `styles` | `StylesPropWithoutWidth` | — | Spectrum-defined styles returned by the style macro. |
| `UNSAFE_className` | `UnsafeClassName` | — | Custom class name, intended only as a last resort. |
| `UNSAFE_style` | `CSSProperties` | — | Inline style, intended only as a last resort. |
