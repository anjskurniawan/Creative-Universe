## Controlled value

Use `value` and `onChange` when the entered text needs to be stored in application state. Use `defaultValue` for an uncontrolled initial value.

<Source language="tsx" code={`import {useState} from "react";
import {TextField} from "@/components/spectrum/TextField";

function Example() {
  const [name, setName] = useState("");
  return <TextField label="Name" value={name} onChange={setName} />;
}`} />

## Validation and form integration

Use `isRequired`, `minLength`, `maxLength`, `pattern`, `type`, `validate`, `isInvalid`, and `errorMessage` to communicate validation rules. Provide `name` when submitting the field in a form.

## Accessibility and internationalization

Provide a visible `label` whenever possible. Use `aria-label` only when a visible label cannot be provided. TextField follows the locale and direction from the consuming Spectrum Provider.

## API and Controls

All props are forwarded to the React Spectrum S2 TextField. Important props include `label`, `description`, `placeholder`, `value`, `defaultValue`, `onChange`, `prefix`, `size`, `isDisabled`, `isReadOnly`, `isRequired`, `isInvalid`, `errorMessage`, `type`, and `name`.
