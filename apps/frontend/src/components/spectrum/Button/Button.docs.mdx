# Button

Buttons allow users to perform an action. This wrapper exposes the React Spectrum S2 Button API while applying the local Spectrum baseline automatically.

## Basic usage

Use the `Button` component with an `onPress` handler. The `onPress` event works consistently with mouse, keyboard, and touch interactions.

<Canvas of={Stories.Primary} />

## Variants and sizes

Use `variant` to communicate the action hierarchy and `size` to match the surrounding layout. `fillStyle="outline"` creates an outlined button.

<Canvas of={Stories.VariantsAndSizes} />

## Disabled and pending states

Use `isDisabled` when the action cannot currently be performed. Use `isPending` for asynchronous work; pending buttons remain focusable while their interaction is disabled and Spectrum announces the pending state.

<Canvas of={Stories.Disabled} />

<Canvas of={Stories.Pending} />

## Events

Use `onPress`, `onPressStart`, `onPressEnd`, or `onPressChange` for interaction callbacks. These callbacks are local Storybook fixtures and do not call an external service.

<Canvas of={Stories.PressEvents} />

## Accessibility and theming

Use visible text for the action whenever possible. For icon-only buttons, provide an accessible `aria-label`. Button styles, color scheme, focus behavior, and keyboard interaction are provided by React Spectrum S2. Verify the component in both Spectrum Light and Dark themes.

## API
