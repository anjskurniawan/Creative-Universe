<Description>
ActionButtons allow users to perform an action. They are used for similar, task-based options within a workflow and are ideal for interfaces where buttons are not meant to draw a lot of attention. This wrapper automatically applies React Spectrum S2 styling, typography, color schemes, and accessibility behavior.
</Description>

## QA color scheme

Use the **Spectrum Light** or **Spectrum Dark** toolbar control in Storybook to inspect every state in both color schemes.

## Basic usage

<Source language="tsx" code={`import { ActionButton } from "@/components/spectrum/ActionButton";

<ActionButton>Edit</ActionButton>`} />
<Primary />

ActionButtons can contain an icon, text, avatar, or other Spectrum content. Provide `aria-label` when the button has no visible text label.

<Source language="tsx" code={`import { ActionButton } from "@/components/spectrum/ActionButton";
import Cut from "@react-spectrum/s2/icons/Cut";

<ActionButton aria-label="Cut"><Cut />Cut</ActionButton>`} />

## Events

Use `onPress` to handle mouse, keyboard, and touch interactions. `onPressStart`, `onPressEnd`, and `onPressChange` are also emitted during the interaction lifecycle.

<Source language="tsx" code={`import { useState } from "react";
import { ActionButton } from "@/components/spectrum/ActionButton";

function Example() {
  const [count, setCount] = useState(0);

  return (
    <ActionButton onPress={() => setCount((value) => value + 1)}>
      {count} Edits
    </ActionButton>
  );
}`} />

## Pending

Set `isPending` to display an indeterminate spinner. Pending buttons remain focusable but do not accept press or hover interactions while pending.

<Source language="tsx" code={`import { useState } from "react";
import { ActionButton } from "@/components/spectrum/ActionButton";

function PendingButton() {
  const [isPending, setPending] = useState(false);

  return (
    <ActionButton
      isPending={isPending}
      onPress={() => {
        setPending(true);
        setTimeout(() => setPending(false), 5000);
      }}>
      Save
    </ActionButton>
  );
}`} />

## Appearance and state

- `isQuiet` applies the quiet ActionButton style.
- `isDisabled` disables the button.
- `size` supports `XS`, `S`, `M`, `L`, and `XL`.
- `staticColor` supports `auto`, `black`, and `white` when the button appears over a colored background.
- Use `type="submit"` or `type="reset"` when the button participates in a form.
